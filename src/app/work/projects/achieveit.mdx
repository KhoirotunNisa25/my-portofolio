AchieveIT is a specialized web platform built to streamline the documentation and analysis of student achievement records, ensuring data is both organized and easily accessible.

## Contributions

I designed the **user flow**, wireframes, and interactive prototypes using Figma. My focus was on enhancing the clarity of the user journey and maintaining a consistent, intuitive experience across every screen.

## Deliverables

* **User Flow & Information Architecture:** Mapping out a logical path for users to navigate the data.
* **Low-Fidelity & High-Fidelity Wireframes:** Transforming conceptual ideas into detailed visual blueprints.
* **Interactive Figma Prototype:** Creating a clickable model to demonstrate functionality and transitions.
* **Design System & UI Components:** Building a reusable library of elements to ensure visual harmony.
