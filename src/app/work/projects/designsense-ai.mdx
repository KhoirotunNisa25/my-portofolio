DesignSense AI is a web application that provides automated UI/UX feedback by analyzing UI screenshots with multimodal AI. Users upload a screenshot and instantly receive structured insights about usability, accessibility, hierarchy, and design consistency.

---

# 1. Background

UI/UX evaluation often requires senior designers, usability testing, or time-consuming manual review. This project helps designers and developers get fast, early feedback before formal testing.

---

# 2. Goals

- Understand UI screenshots and extract design signals.
- Identify usability and accessibility issues.
- Provide structured, actionable recommendations.
- Speed up design review for early iteration.

---

# 3. System Flow

```txt
User Upload Screenshot
↓
Frontend Preview
↓
Image sent to Next.js API route
↓
Gemini Vision analyzes the UI
↓
AI returns structured feedback
↓
Results shown as cards and scores
```

---

# 4. Core Features

### 1) Screenshot Upload

Supports landing pages, mobile UI, dashboards, forms, and other interface screenshots.

### 2) AI UI/UX Analysis

Analysis covers:

- Visual hierarchy
- Spacing and alignment
- Readability
- CTA visibility
- Consistency
- Accessibility
- UX issues

### 3) Structured Feedback

AI responses are grouped into sections:

```txt
Visual Hierarchy
Accessibility
Layout Consistency
UX Issues
Suggestions
```

### 4) AI Scoring

- Accessibility Score
- Visual Consistency Score
- UX Clarity Score

### 5) Modern Responsive UI

A minimal, card-based layout with clear states and responsive design.
