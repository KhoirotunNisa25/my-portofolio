A professional foundation profile website designed to present organizational information clearly while supporting web-based internal data management.

## Contributions

I designed a **clean and informative** user interface and spearheaded the development of core features using **Laravel**, including the content management system (CMS) and the secure administrative dashboard.

## Key Features

* **Foundation Profile & Info:** A comprehensive section for organizational history, vision, and mission.
* **Programs & Activities Pages:** Dedicated modules to showcase the foundation's initiatives and community impact.
* **Internal Admin Panel:** A robust backend for managing organizational data and site content efficiently.
* **Responsive & Professional Design:** Fully optimized for seamless viewing across desktops, tablets, and mobile devices.
